# Python Arithmetic Operations and Comparisons

A beginner-friendly Python program demonstrating arithmetic operators, variables, numeric data types, comparison operators, logical operators, and membership operators.

## 📌 Overview

This repository contains a simple Python script that introduces the fundamentals of Python programming. It covers:

* Arithmetic operations
* Integer, float, and complex numbers
* Variables and assignments
* Area and weight calculations
* Comparison operators
* Boolean values
* Logical operators
* Identity operators
* Membership operators

This program is ideal for beginners who are learning Python basics.

---

## 📂 Topics Covered

### 1. Arithmetic Operators

The program demonstrates:

| Operator | Description         | Example  |
| -------- | ------------------- | -------- |
| `+`      | Addition            | `2 + 3`  |
| `-`      | Subtraction         | `5 - 2`  |
| `*`      | Multiplication      | `4 * 6`  |
| `/`      | Division            | `7 / 2`  |
| `//`     | Floor Division      | `7 // 2` |
| `%`      | Modulus (Remainder) | `7 % 2`  |
| `**`     | Exponentiation      | `3 ** 2` |

---

### 2. Numeric Data Types

Examples of:

* Integers
* Floating-point numbers
* Complex numbers

Example:

```python
print(3.14)
print(1 + 1j)
```

---

### 3. Variables

Demonstrates storing values in variables and performing calculations.

Example:

```python
a = 3
b = 2

total = a + b
product = a * b
```

---

### 4. Practical Calculations

The program calculates:

* Area of a circle
* Area of a rectangle
* Weight using the formula:

```text
Weight = Mass × Gravity
```

---

### 5. Comparison Operators

Examples include:

* Greater than (`>`)
* Less than (`<`)
* Equal to (`==`)
* Not equal to (`!=`)
* Greater than or equal to (`>=`)
* Less than or equal to (`<=`)

---

### 6. Boolean Operations

Demonstrates:

```python
True == True
True and False
True or False
not True
```

---

### 7. Identity Operators

Examples using:

```python
is
is not
```

---

### 8. Membership Operators

Checks whether a value exists inside a string.

Example:

```python
'A' in 'Asabeneh'
'coding' in 'coding for all'
```


3. Run the program:

```bash

```
